# Python + CUDA compatibility

# This project was developed and tested with the following environment.
# The optional CUDA-kernel packages (mamba-ssm)
# MUST be compiled against your EXACT Python + PyTorch + CUDA versions —
# mixing versions = segfaults.
#
#   Python        3.12
#   CUDA toolkit  13.0  (or 12.x — torch 2.11 also ships cu124 wheels)
#   PyTorch       2.11.0+cu130        # pip install torch==2.11.0 --index-url https://download.pytorch.org/whl/cu130
#   mamba-ssm     2.3.2.post1         # custom wheel, built for cp312 + cu13 + torch2.11
#
# To match this exact stack on a fresh machine:
#
#   1. Install CUDA 13.0 toolkit (or at least the driver, ~R560+)
#   2. conda create -n vjepa2-312 python=3.12
#   3. pip install torch==2.11.0 torchvision==0.26.0 --index-url https://download.pytorch.org/whl/cu130
#   4. pip install -r requirements.txt
#   5. Build mamba-ssm from source or find a pre-built wheel for your versions:
#        pip install mamba-ssm
#      See: https://github.com/state-spaces/mamba
#   6. Build flash-attn from source or grab a pre-built wheel:
#        pip install flash-attn --no-build-isolation
#      Pre-built wheels: https://github.com/Dao-AILab/flash-attention/releases
#
# Core dependencies are required for all temporal model variants.
# Optional sections can be installed selectively.
